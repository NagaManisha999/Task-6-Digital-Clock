# Real-Time Digital Clock

A clean and responsive digital clock built using HTML, CSS, and JavaScript. The project displays the user's current local time and updates automatically every second through JavaScript.

## Features

- Real-time clock updates every second
- 12-hour time format with AM/PM
- Current date and day display
- Automatic time formatting with leading zeros
- Responsive layout for desktop, tablet, and mobile
- Clean and modern user interface
- Lightweight implementation using only HTML, CSS, and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript
